NOTA: Para completar la PWA necesitas crear los iconos PNG

Necesitas crear:
- icon-192.png (192x192px)
- icon-512.png (512x512px)

Puedes usar el archivo puzzle-icon.svg como base y convertirlo a PNG usando:
- https://cloudconvert.com/svg-to-png
- https://realfavicongenerator.net/
- Photoshop/GIMP/Figma

O simplemente usa una herramienta online para generar favicons a partir del SVG.

Mientras tanto, la app funcionará pero no tendrá iconos al instalarse.
